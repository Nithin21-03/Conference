# Conference Uploads Directory

This folder securely stores paper manuscripts submitted by authors for the International Conference on Big Data Tools and Techniques (ICBDTT-2026).

Files are named securely with their unique Paper ID and randomized cryptographic hashes to prevent collisions and path traversal attacks (e.g. `SNPSU-BDTT-P-4821_a9f2b1c4.pdf`).

Supported formats:
- PDF (.pdf)
- Microsoft Word (.doc, .docx)
